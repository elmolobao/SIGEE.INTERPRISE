# SIGEE Enterprise RC12.0.0 — Fundação Legalização Escolar

## Objetivo
Criar a fundação independente do módulo Legalização Escolar sem alterar o workflow homologado de Escolas Extintas.

## Implementado
- autoridade de acesso por módulo (`ESCOLAS_EXTINTAS` / `LEGALIZACAO`);
- vínculo usuário × módulo × perfil × NTE;
- compatibilidade automática para usuários atuais de Escolas Extintas;
- Master com acesso aos dois domínios;
- menu e rota independentes para Legalização;
- tela inicial do módulo com indicadores e cadastro de instituição;
- NTE fixado no cadastro para usuário territorial; Master escolhe o NTE na criação;
- tabelas-base de instituições, processos regulatórios, ofertas/vigências, checklists e inspeções;
- catálogo inicial do Anexo I (credenciamento) e Anexo III (autorização/renovação) da Resolução CEE/BA nº 26/2016.

## Regra de autorização
O usuário permanece em `usuarios_sigee`. O acesso funcional passa a ser complementado por `usuarios_modulos_sigee`.
Usuários atuais são migrados para `ESCOLAS_EXTINTAS`. Legalização somente aparece para usuário vinculado ao módulo, ou Master.

## Banco
Executar `supabase/migrations/20260901_rc12_0_0_fundacao_legalizacao.sql` antes de testar o novo módulo.

## Segurança
A autenticação atual do SIGEE é customizada e usa o cliente anon do Supabase. Portanto, a segregação fina por identidade continua sendo autoridade da aplicação, como já ocorre em outros módulos. As tabelas novas deixam RLS habilitada em modo compatível até uma futura camada de identidade autenticada no banco.
