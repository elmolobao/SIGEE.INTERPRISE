# SIGEE RC11.3.18 — Tratamento selecionável

## Regra funcional
Toda constatação negativa passa a exigir a escolha de um **Tipo de tratamento**:

- **Monitoramento**: permanece no Monitoramento Territorial, pode receber orientação/reunião/acompanhamento, mas não gera tarefa no Plano de Ação e não recupera conformidade por validação de tarefa.
- **Ação Corretiva**: gera/reativa Plano de Ação Territorial, exige execução/evidência pelo NTE e validação da Gestão Master. A conformidade atual somente é recuperada após validação/conclusão.

Relevância e tratamento são independentes.

## Compatibilidade
`requer_acao_corretiva` continua existindo e é sincronizado com `tratamento_tipo` para compatibilidade.

## Alteração de tratamento
- Ação Corretiva -> Monitoramento: permitida somente se a tarefa ainda estiver **PENDENTE**. A tarefa passa a **CANCELADA** e sai das métricas/da lista, preservando histórico.
- Se a tarefa já estiver em execução, aguardando validação, devolvida ou concluída, a conversão é bloqueada para preservar a auditoria.
- Monitoramento -> Ação Corretiva: cria nova tarefa ou reativa a tarefa cancelada.

## Instalação
1. Executar `supabase/migrations/20260831_rc11_3_18_tratamento_selecionavel.sql`.
2. Publicar os arquivos do frontend.
3. Limpar cache/recarregar o navegador.

## Teste mínimo
1. Criar negativa com **Monitoramento**: não deve aparecer no Plano de Ação.
2. Criar negativa com **Ação Corretiva**: deve aparecer no NTE correspondente.
3. Alterar uma tarefa PENDENTE para **Monitoramento**: deve desaparecer do Plano, mas ficar no histórico como CANCELADA.
4. Reverter para **Ação Corretiva**: a tarefa deve ser reativada.
